# Day 01 - Summer Training Daily Diary

## Training Domain
**Artificial Intelligence & Machine Learning (AI & ML) using Python**

---

## Objective

The first day of the training was focused on understanding the basics of Python programming. The session covered variables, data types, memory references, type conversion, collection data types, and Python operators. Along with the theory, practical exercises were performed to understand how these concepts are used in programming.

---

## Tasks Assigned by the Industry Expert

During today's session, the following tasks were assigned:

1. Learn the concept of Python variables and object references.
2. Explore different built-in data types in Python.
3. Understand the difference between mutable and immutable objects.
4. Practice implicit and explicit type conversion.
5. Follow Python variable naming conventions.
6. Work with Python collection data types.
7. Implement programs using different categories of Python operators.

---

## Practical Work Completed

During the practical session, I worked on the following activities:

- Created Python programs using variables and user input.
- Used the `type()` function to identify different data types.
- Used the `id()` function to observe object identity and memory references.
- Practiced reference sharing between variables.
- Performed examples to understand mutable and immutable objects.
- Applied type conversion using `int()`, `float()`, `str()`, `list()`, `tuple()`, and `set()`.
- Worked with Python collection data types such as Lists, Tuples, Dictionaries, and Sets.
- Developed a simple Student Result Card program to display Pass/Fail status based on marks.
- Practiced different categories of Python operators through programming examples.

- Dynamic typing in Python.
- Reference sharing between variables.

- String (`str`)
- Boolean (`bool`)
- NoneType
- List

- Comparison Operators

- Membership Operators
