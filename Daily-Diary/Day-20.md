# Day 20 - Summer Training Daily Diary

## Training Domain
**Artificial Intelligence & Machine Learning (AI & ML) using Python**

---

## Objective

The objective of today's training was to understand the basics of Unsupervised Learning and learn how the K-Means Clustering algorithm groups similar data without using predefined labels. The session also included practical work on customer segmentation using the Mall Customers dataset.

---

## Tasks Assigned by the Industry Expert

The following tasks were assigned during today's training session:

1. Understand the concept of Unsupervised Learning and clustering.
2. Explore the Mall Customers dataset.
3. Select suitable features for clustering.
4. Apply feature scaling before building the model.
5. Build a K-Means Clustering model using Scikit-learn.
6. Visualize customer clusters and identify cluster centroids.
7. Interpret the clustering results.

---

## Work Performed

During today's practical session, I completed the following activities:

- Loaded the Mall Customers dataset using Pandas.
- Explored the dataset using `head()`, `info()`, `describe()`, and `isnull().sum()`.
- Studied the available features such as Age, Annual Income, and Spending Score.
- Created a scatter plot to observe the distribution of customer data.
- Selected Annual Income and Spending Score as the input features for clustering.
- Applied `StandardScaler` to normalize the selected features.
- Built a K-Means Clustering model using Scikit-learn.
- Generated cluster labels for all customer records.
- Visualized the customer groups along with their cluster centroids.
- Observed how customers were divided into different segments based on similar characteristics.
