# Day 22 - Summer Training Daily Diary

**Artificial Intelligence & Machine Learning (AI & ML) using Python**

## Objective

The objective of today's training was to understand the basics of OpenCV and learn how to perform simple image processing operations using Python. The session focused on reading images, displaying them, exploring image properties, converting images to grayscale, resizing images, and understanding the importance of image preprocessing in computer vision.

---

## Tasks Assigned by the Industry Expert

The following tasks were assigned during today's training session:

1. Understand the basics of OpenCV and its applications.
2. Import the required OpenCV library in Python.
3. Load and display images using OpenCV functions.
4. Explore image properties such as size and dimensions.
5. Convert color images into grayscale.
6. Resize images using different dimensions.
7. Practice basic image preprocessing operations.

---

## Work Performed

During today's practical session, I completed the following activities:

- Imported the OpenCV (`cv2`) library.
- Loaded image files using `cv2.imread()`.
- Displayed images using OpenCV and closed the image windows using keyboard input.
- Examined image properties such as height, width, channels, and shape.
- Converted color images into grayscale using `cv2.cvtColor()`.
- Resized images using different dimensions to observe the changes.
- Compared original and processed images after resizing and grayscale conversion.
- Practiced basic image preprocessing techniques used before applying computer vision algorithms.
- Explored the basic workflow of handling images using OpenCV.
