## Objective

The objective of today's training was to learn image manipulation techniques and drawing functions using OpenCV. The session focused on editing images, drawing different shapes, adding text, and understanding how these operations are used in computer vision applications.

---

## Tasks Assigned by the Industry Expert

The following tasks were assigned during today's training session:

1. Learn basic image manipulation using OpenCV.
2. Crop and modify images using Region of Interest (ROI).
3. Draw different shapes on images.
4. Add text annotations using OpenCV.
5. Adjust colors, thickness, and drawing positions.
6. Save the modified images.
7. Practice image annotation techniques used in computer vision.

---

## Work Performed

During today's practical session, I completed the following activities:

- Loaded image files using OpenCV.
- Accessed and modified selected image regions using Region of Interest (ROI).
- Cropped specific portions of images for editing.
- Drew lines, rectangles, and circles using OpenCV drawing functions.
- Created simple image annotations by combining different drawing tools.
- Added customized text to images using `cv2.putText()`.
- Changed drawing colors, thickness, and positions according to the requirement.
- Saved the processed images using `cv2.imwrite()`.
- Practiced different image manipulation techniques through hands-on exercises.

## Topics Covered

### Image Manipulation
- Accessing image pixels.
- Region of Interest (ROI).
- Image cropping.
- Copying and modifying image regions.

### Drawing Operations
- Drawing lines using `cv2.line()`.
- Drawing rectangles using `cv2.rectangle()`.
- Drawing circles using `cv2.circle()`.
- Creating simple graphical annotations.

### Adding Text
- Writing text using `cv2.putText()`.
- Selecting font style.
- Adjusting font size, color, and thickness.
- Positioning text on images.

### Saving Images
- Saving processed images using `cv2.imwrite()`.
- Managing output image files.

### Applications of Drawing Functions
- Image annotation.
- Object highlighting.
- Bounding box creation.
- Computer vision applications.
